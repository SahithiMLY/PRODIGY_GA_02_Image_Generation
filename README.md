# PRODIGY_GA_02 - Image Generation with Pre-trained Models

## Objective
Generate images from text prompts using a pre-trained Stable Diffusion model.

## Tools Used
- Python
- TensorFlow
- KerasCV
- Stable Diffusion
- Google Colab

## Description
This project demonstrates text-to-image generation using TensorFlow's KerasCV implementation of Stable Diffusion. The model takes natural language prompts as input and generates realistic images.

## Sample Prompts
1. A futuristic city with flying cars at sunset
2. A cute panda drinking coffee in a cafe
3. A robot studying in a college classroom
4. A cyberpunk city during rain at night

## Outcome
Successfully generated AI images from text prompts using a pre-trained generative AI model.
